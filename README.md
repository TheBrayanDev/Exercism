# Exercism Solutions

My solutions to the programming exercises from [Exercism.org](https://exercism.org), organized by programming language.

## Languages

- Python (`solutions/python/`)
- C++ (`solutions/cpp/`)

## Structure

Each language has its own directory, and every exercise lives in its own folder inside it:

```
├── python/
│   └── hello-world/
└── cpp/
    └── hello-world/
```

## Running the Tests

Exercises can be tested locally with the Exercism CLI. From inside an exercise directory:

```bash
exercism test
```

And to submit a solution:

```bash
exercism submit <implementation_file_paths>
```

## Getting Started

1. [Install the Exercism CLI](https://exercism.org/cli-walkthrough)
2. Sign up at [exercism.org](https://exercism.org)
3. Download exercises with `exercism download --track=<track> --exercise=<slug>`

## Disclaimer

These are my personal solutions, written for learning purposes. If you are working through Exercism yourself, I encourage you to attempt each exercise on your own before looking at these.
